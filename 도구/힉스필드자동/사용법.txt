Higgsfield 자동 뽑기 · 사용법
================================

하는 일
  UI그림_번호표.csv 와 UI그림_프롬프트_전체.txt 를 읽어서 번호마다
  프롬프트 넣기 → 첨부1·첨부2 그림 올리기 → 생성 → 결과 원본 받기
  → 저장폴더\파일이름 으로 PNG 저장 → 약 3분 쉬기 → 다음 번호.
  이미 저장된 번호는 건너뜁니다 (UI 그림 도우미와 같은 폴더·이름이라 거기서도 «저장됨» 으로 보임).

처음 한 번
  0. 파이썬이 없으면 python.org 에서 설치 (설치 화면에서 «Add python.exe to PATH» 체크)
  1. 1_설치.bat
  2. 2_크롬열기.bat → 새 크롬 창이 열림 (자동 전용 창 · 평소 크롬과 따로)
     그 창에서 Higgsfield 로그인 (처음 한 번만, 다음부터는 로그인 유지)
  3. 그 창에서 쓸 생성 화면 (Nano Banana Pro) 을 열고
     해상도 2K · 비율 · 한 번에 1장 으로 맞춤
  4. 3_위치정하기.bat → 까만 창에서 Enter → 크롬 위쪽 노란 안내대로
     ① 프롬프트 입력칸 ② 사진 첨부 단추 ③ 생성 단추 를 차례로 클릭
     (클릭해도 실제로 생성되지는 않음)
  5. 4_시험1개.bat → 하나만 뽑아 봄. 저장 폴더에 제대로 들어갔는지 확인
     ★ 이때 Higgsfield 크레딧이 줄지 않는지 (Unlimited 로 뽑히는지) 꼭 확인

자기 전
  2_크롬열기.bat (창이 닫혀 있으면) → 5_밤새돌리기.bat
  - 컴퓨터는 켜 두기 (프로그램이 도는 동안 절전 모드로 안 들어가게 해 둠)
  - 자동 크롬 창은 최소화해도 됨, 닫으면 안 됨

멈추기
  까만 창에서 Ctrl+C · 또는 이 폴더에 STOP.txt 파일을 만들면 지금 번호까지 하고 멈춤

골라서 돌리기 (5_밤새돌리기.bat 를 까만 창에서 실행할 때 뒤에 붙임)
  --from 10 --to 50     10~50번만
  --stage 1단계          단계 칸에 «1단계» 인 것만
  --count 30            30개만
  --gap 240             쉬는 시간 240초 (기본 180초 ± 30초 무작위)

결과 · 기록
  hf_log.csv            번호마다 저장 / 실패 / 작음 기록
  실패_번호.png         실패한 순간의 화면
  저장폴더\_작은그림\    1500px 보다 작게 받힌 그림 (원본을 못 찾은 것 · 확인 필요)
  저장폴더\_이전\        덮어쓰기 전에 있던 그림
  연속 3번 실패하면 스스로 멈춤 (로그아웃 · 화면 바뀜 · 크레딧 부족 등)

설정 (hf_settings.json · 3_위치정하기 후 생김)
  작업폴더   번호표·프롬프트 파일이 있는 폴더 (기본 C:\Users\User\클로드\side\art\UI\UI 그림 작업)
  간격초 180 · 간격흔들기초 30 · 최대대기초 900 · 최소가로 1500 · 올린뒤대기초 8
  Higgsfield 화면이 바뀌어 실패하면 3_위치정하기.bat 를 다시 하면 됨

주의
  사이트 자동화는 Higgsfield 약관에 걸릴 수 있어요. 간격을 너무 줄이지 마세요.
